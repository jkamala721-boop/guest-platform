# Hostvero

Hostvero is a host-only guest management platform for short-term rental operators, serviced apartments, guesthouses, and small hotels.

## Stack

- Java 21
- Spring Boot
- Maven
- PostgreSQL / Supabase
- HTML
- CSS
- JavaScript
